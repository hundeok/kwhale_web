# K-Whale 로드맵

## 현재 단계

프로젝트는 핵심 데이터 엔진과 주요 분석 메뉴를 갖춘 중반 이후 단계다.
증권·가상자산·대시보드·인물·공직자·증감·신규자산·부동산 메뉴는 제품 수준의
기본 구조를 갖췄고, 전국 자산 지도를 대표 기능으로 고도화하는 중이다.

## P0. 전국 자산 지도 마감

- 좌표 회귀 테스트 자동화
- 클러스터 그래픽 정보 밀도와 가독성 조정
- 줌 단계별 표현 규칙 정리
- 지역→기관→인물→개별 자산 탐색 연결
- 대표 좌표·상세 좌표 신뢰도 시각화
- 모바일 상세 패널과 필터 동선 검증
- 대용량 성능과 메모리 프로파일링

## P0. 데이터 신뢰도 마감

- 공식 원문 건별 대조 큐 확대
- 중복 좌표·주소 품질 보고서
- 종목·코인 별칭 검토 큐
- 2026년 진행 중 공개분 자동 갱신
- 릴리스별 회계 불변식 자동 게이트

## P1. 엔티티 페이지

- 증권 종목 상세
- 가상자산 상세
- 부동산 지역 상세
- 기관 상세
- 자산 유형 상세
- 모든 카드·표·지도 요소를 동일 엔티티로 연결

## P1. 관계 그래프

- 인물–기관–자산–지역–연도 관계 모델
- 동일 자산 연도 추적
- 별칭과 법인명 정규화
- 관계별 근거 원문과 신뢰도
- 그래프 탐색 API와 캐시

## P1. 운영·배포

- [완료] 환경변수와 비밀정보 분리
- [완료] 공개 API projection 및 Turso 배포
- [완료] Git push 기반 Vercel 자동 배포
- [완료] 도쿄 동지역 배치·CDN 캐시·배포 후 예열
- 에러 로깅과 성능 관측
- 접근성·키보드 탐색
- SEO·공유 카드
- 개인정보·이용약관 최종 법률 검토
- 자동 백업과 롤백 런북

## P2. 고급 분석

- 연도별 자산 흐름 타임라인
- 기관·직책 코호트 분석
- 주소·종목 정규화 신뢰도 개선
- 알파 엔진의 표본·민감도·안정성 보고
- 원문 변경 감지와 자동 재처리

- 네이버/카카오 베이스맵 교체: 현재 MapLibre 방식이 병목일 때 비교 실험
