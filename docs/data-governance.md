# 데이터 거버넌스

## 1. 출처 우선순위

1. 대한민국 전자관보와 기관 공식 공보
2. PETI 공개 자료
3. 리얼시그널 공개 정제 데이터
4. 과거 K-Whale 스냅샷

낮은 우선순위 데이터는 삭제하지 않고 비교 증거로 보존한다. 값이 충돌하면
공식 원문을 우선하고 충돌 기록을 남긴다.

## 2. 데이터 계층

- 원본: 다운로드한 파일·응답을 내용 주소 방식으로 불변 보존
- lineage: URL, 수집 시각, 해시, 파서 버전, 검증 결과
- raw row: 원문 표현을 가능한 그대로 보존
- normalized: 검색과 집계를 위한 정규화 결과
- derived: 순위, 변화량, 집중도, 알파 인사이트
- projection: 프런트엔드에 필요한 최소 API 응답

원본과 정규화 결과를 같은 필드로 덮어쓰지 않는다.

## 3. 공개값 분류

### 공식값

- 인물별 공식 신고총액
- 원문 자산 행 평가액
- 원문에서 직접 확인 가능한 종목별 금액
- 소속·직위·공개일·기준 연도

### 파생값

- 종목명 정규화
- 동일 자산 연도 매칭
- 보유자 수
- 집중도·모멘텀·알파 인사이트
- 지역·기관별 집계

파생값에는 계산식, 모집단, 최소 표본과 신뢰도를 함께 제공한다.

## 4. 신뢰등급

공통 개념:

- A: 공식 원문에서 값과 대상이 직접 연결됨
- B: 원문 구조상 연결되며 정규화 근거가 충분함
- C: 대상은 식별되나 금액·관계 일부를 배분할 수 없음
- D: 명칭·주소·관계가 모호하여 검토 필요

가상자산 예:

- A: 단일 코인과 금액 직접 확인
- B: 복수 코인이지만 개별 금액 명시
- C: 코인은 식별되나 합산 금액 미배분
- D: 미확인 명칭 또는 정규화 미완료

지도 예:

- 상세 주소 좌표: 하나의 상세 주소와 고유 좌표가 연결됨
- 대표 좌표: 상세 주소가 없거나 서로 다른 주소가 동일 좌표를 공유함
- 미표시: 대한민국 유효 범위 밖이거나 좌표가 없음

## 5. 회계 불변식

```text
순자산 = 총자산 - 채무
```

```text
가상자산 공식 신고총액
= 코인별 직접 귀속 금액
+ 코인별 미배분 금액
```

```text
증권 공식 신고총액
= 종목별 직접 귀속 금액
+ 종목별 미배분 금액
```

하나의 원문 행이 여러 종목에 중복 귀속되지 않아야 한다.

## 6. 연도와 스냅샷

- 배포 연도, 등록일, 공개일, 화면 기준 연도를 별도 필드로 보존한다.
- 인물별 최신 통합은 동일 인물의 가장 최신 공개분을 선택한다.
- 연도 비교는 현재와 직전 스냅샷이 모두 있을 때만 수행한다.
- 신규취득은 시장 매수와 동일한 의미가 아니다. 신고서상 신규·증가 관계다.
- 2026년은 진행 중 공개분이므로 표본이 완결 연도보다 작을 수 있다.

## 7. 명칭 정규화

- `rawName`: 원문 명칭
- `canonicalName`: 화면 대표 명칭
- aliases: 한글·영문·티커·오탈자·법인 표기
- entity type: 상장주식, 비상장, 채권, 코인, NFT, 예금성 상품 등
- review state: 자동 확정, 검토 후보, 미확인

원문 명칭을 삭제하지 않는다. 별칭 통합은 되돌릴 수 있어야 한다.

## 8. 지도 좌표 정책

- 원본 위경도는 수정하지 않고 별도 보정 필드를 사용한다.
- 화면에서 주소 정밀도를 과장하지 않는다.
- 동일 좌표에 서로 다른 상세 주소가 2개 이상이면 대표 좌표로 하향한다.
- 대청도·백령도 등 도서 지역은 대한민국 유효 좌표이며 지리적 위치를 유지한다.
- 클러스터 중심은 자산 위치의 공간 묶음이며 행정청 소재지를 뜻하지 않는다.

## 9. 비공개·배포 금지

- `backend/private-data` 전체
- SQLite DB 직접 다운로드
- 수집 응답 헤더와 내부 경로
- 전체 원문 덤프
- 검토되지 않은 개인 단위 원문 대량 projection

공개 API는 화면에 필요한 최소 필드와 페이지 단위 결과만 제공한다.

## 10. 변경 승인 기준

다음 변경은 데이터 품질 작업으로 간주한다.

- 분류 사전 변경
- 금액 계산식 변경
- 연도 선택 정책 변경
- 인물·자산 동일성 매칭 변경
