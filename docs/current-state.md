# 현재 작업 상태

마지막 갱신: 2026-07-29

이 문서는 영구 원칙이 아니라 현재 개발 지점을 빠르게 인수인계하기 위한
스냅샷이다. 기능 변경 후 날짜와 내용을 갱신한다.

## 실행 상태

- 프런트엔드 기본 주소: `http://127.0.0.1:5173`
- private API: `http://127.0.0.1:3340`
- Vite `/api` 프록시: 3340
- 기본 테마: 다크
- 기본 연도 정책: `recent`

## 현재 데이터 기준

지도 API의 최근 통합 기준 화면에서 확인된 값:

- 지도 반영 자산: 47,382건
- 원본 부동산 자산: 50,029건
- 보유 공직자: 6,578명
- 공식 신고가액: 약 8.8조 원
- 좌표 포괄률: 약 94.7%

릴리스 갱신 시 수치는 바뀔 수 있다. 이 문서의 숫자를 코드에 하드코딩하지
않는다.

## 전국 자산 지도 진행점

완료:

- MapLibre + CARTO Voyager 베이스
- Supercluster 기반 대용량 클러스터
- 건수·신고가액 렌즈
- 지역·자산군·금액·좌표 신뢰도·기관·직책·명의 필터
- 클러스터 상세와 개별 자산 상세
- 선택 자산 URL 복원
- 인물별 전국 자산 포커스
- 지도 진입 시 사이드바 자동 축소
- `전국` 클릭 시 모든 필터와 지도 위치 초기화
- 동일 좌표를 공유하는 서로 다른 주소의 신뢰도 자동 하향

현재 그래픽 구조:

```text
MapLibre marker element
└─ .asset-cluster-visual
```

좌표 앵커는 건드리지 않고 내부 소나 그래픽만 적용한 상태다.

최근 회귀 테스트:

- 전국 기본 클러스터: 24개
- 1단계 확대: 49개
- 2단계 확대: 69개
- 크래시·undefined 오류 없음

수치는 뷰포트와 릴리스에 따라 달라질 수 있으며, 핵심은 확대할수록 정상적으로
분화되고 좌표가 지도와 동시에 움직이는지다.

## 최근 좌표 품질 사례

- 김규성, 대청면 대청리 415-14: 대청도 위치는 정상. 서로 다른 주소 7건이
  같은 좌표를 공유해 대표 위치로 하향.
- 김규성, 대청면 대청리 산 73-2: 대청도 위치는 정상. 서로 다른 주소 2건이
  같은 좌표를 공유해 대표 위치로 하향.
- 신경원, 백령면 진촌리 115: 백령도 위치는 정상. 상세 필지 좌표 확정 근거가
  부족해 대표 위치로 표시.

도서 지역을 본토로 이동시키지 않는다.
