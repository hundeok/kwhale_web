# 데이터 방법론

## 1. 출처 계보

모든 서비스 값은 다음 경로로 역추적할 수 있어야 합니다.

`화면 값 → 정규화 자산 → 원문 행 → 원문 파일 위치 → SHA-256 → 공식 URL`

출처가 없는 기존 자산은 화면에 표시할 수 있지만 연도 비교 랭킹과 신규취득 계산에는 포함하지 않습니다.

### 공식 출처 라우팅

- PETI 통합 검색: 위원회별 공개 목록, 공개일, 공개 유형, 의무자 수,
  등록번호 및 공식 파일 토큰을 연도별로 발견합니다.
- 전자관보: 행정부·사법부·선거관리위원회가 관보에 공개한 장기 원문의
  직접 파일 URL과 해시를 보존합니다.
- 국회·헌법재판소·지방자치단체: 해당 기관 공보를 원문 출처로 기록합니다.
- 인사혁신처 안내는 정기 공개가 매년 3월, 수시 공개가 매월 이루어진다는
  수집 주기와 등록 재산 종류를 결정하는 공식 업무 규칙으로 사용합니다.

PETI의 `optpFlnm`과 `rgsMno`는 URL이 아니라 암호화된 파일·등록 토큰입니다.
따라서 토큰을 URL로 변형하지 않고 원문 그대로 저장하며, PETI의 다운로드
컴포넌트 또는 PDF 생성 절차가 반환한 파일만 공식 원문으로 인정합니다.

## 2. 금액

- 내부 금액 단위는 원(KRW) 정수 `BigInt`입니다.
- 원문의 단위가 천원인 경우 1,000을 곱합니다.
- 외화는 환율 기준일과 환율 출처가 없으면 원화 평가액으로 재계산하지 않습니다.
- 채무 원문 금액은 양수로 보존할 수 있지만 집계 시 `liabilities`에 절댓값으로 더합니다.

```text
grossAssets = 부채가 아닌 양수 자산 합계
liabilities = 채무 평가액 절댓값 합계
netWorth = grossAssets - liabilities
```

## 3. 카테고리

원문 카테고리를 덮어쓰지 않습니다.

- `categoryRaw`: 공식 문서의 원문
- `normalizedCategory`: 서비스 중분류
- `normalizedSubcategory`: 세부 유형
- 대분류는 분류 사전의 `group` 사용

분류 사전은 `backend/data/category-taxonomy.json`에서 버전 관리합니다.

## 4. 연도 비교

동일 자산 키는 다음 값으로 구성합니다.

```text
인물 ID + 정규 카테고리 + 세부 유형 + 소유 관계 + 정규 주소/종목
```

- 이전 연도에 없고 현재 연도에 있음: `ACQUIRED`
- 이전 연도에 있고 현재 연도에 없음: `DISPOSED`
- 양쪽에 있고 금액 증가: `INCREASED`
- 양쪽에 있고 금액 감소: `DECREASED`

모호한 매칭은 자동 확정하지 않고 낮은 신뢰도와 검수 상태를 부여합니다.

## 5. 수익금과 수익률

서비스의 “수익금”은 시장 투자수익을 뜻하지 않습니다. 공식 공시 순자산의 연도 간 증감액입니다.

```text
순자산 증감액 = 현재 연도 순자산 - 이전 연도 순자산
순자산 증감률 = 순자산 증감액 / 이전 연도 순자산 × 100
```

증감액에는 매매 손익 외에도 급여, 상속, 증여, 채무 변화, 평가액 변화 등이 포함될 수 있습니다. 화면에는 이 한계를 표시해야 합니다.

## 6. 증권·가상자산

한 원문 행에 여러 종목이 포함된 경우:

- 종목과 수량은 각각 추출합니다.
- 종목별 평가액이 원문에서 분리되지 않으면 `declaredValuation = null`로 둡니다.
- 자산 행 전체 평가액을 각 종목에 반복 배분하지 않습니다.
- 종목별 평가액 집계에는 배분 근거가 있는 레코드만 포함합니다.

## 7. 공개 품질 게이트

다음 조건을 충족하지 않으면 연도 비교 랭킹을 공개하지 않습니다.

- 비교 가능한 공시 연도 2개 이상
- 각 계산값의 공식 출처 연결
- 채무 차감 재계산 완료
- 파서 버전 기록
- 중복 행 검사
- 저신뢰 결과 비율 보고
- 랜덤 또는 하드코딩 값 0건

서비스 품질 보고서는 `npm run data:quality`, 실데이터 전체 파서 보고서는
`npm run data:parser-quality`로 생성합니다. 현재 파서 게이트는 증권·가상자산
수량 추출, 예금·채무 금액 구성요소, 부동산 면적, 차량 연식·배기량 및
평가액 정합성을 각각 측정합니다.
