# 주요 의사결정과 사고 기록

## D-001. `kwhale_web_gpt`를 본진으로 사용

- 상태: 확정
- 이유: 복구된 원본의 장점을 계승하면서 데이터 엔진과 UI를 대폭 개선한 현재
  제품이 실질적 기준선이 됨
- 결과: `kwhale_web`은 보존하고 수정하지 않음

## D-002. 최신 기본값은 `recent`

- 상태: 확정
- 이유: 사용자는 최신 정보를 우선 탐색하지만 진행 중인 2026년만 단독으로
  표시하면 모집단이 지나치게 작음
- 결과: 완결 모집단과 최신 공개분을 인물별 최신 정책으로 결합하고 화면에서
  정책을 명시

## D-003. 가상자산·증권 직접 귀속과 미배분 분리

- 상태: 확정
- 이유: 복수 종목 합산 신고액을 임의 배분하면 종목 랭킹이 왜곡됨
- 결과: 인물 공식 총액과 종목별 직접 귀속 통계를 별도 표시

## D-004. 증감률과 증감액 메뉴 분리

- 상태: 확정
- 이유: 비율 급변과 절대 금액 이동은 서로 다른 탐색 질문
- 결과: 재산 급변 탐지와 고액 자산 이동으로 역할을 분명히 함

## D-005. MapLibre + CARTO Voyager 유지

- 상태: 현재 기준
- 이유: 가볍고 빠르며 K-Whale 데이터 시각화의 자유도가 높음
- 검토 대안: 네이버 지도, 카카오 지도, 프리미엄 벡터 타일
- 재검토 조건: 국내 상세 지도 품질이 제품 가치의 병목이 될 때

## D-006. 지도 그래픽과 좌표 앵커 분리

- 상태: 확정
- 사고: 확대 전환을 부드럽게 만들기 위해 MapLibre 마커 요소에 CSS
  `transform` transition과 교대 렌더링을 적용하면서 좌표가 지도보다 늦게
  따라가는 현상 발생
- 잘못된 접근:
  - 좌표 요소에 scale/transform 애니메이션
  - 이전·새 마커를 잠시 공존
  - 그래픽 변경과 동시에 `@2x` 베이스 타일 변경
- 복구:
  - Voyager 256px 설정 복원
  - 즉시 단일 마커 렌더링 복원
  - 그래픽을 `.asset-cluster-visual` 내부 자식으로 분리
- 영구 규칙: 좌표 컨테이너의 transform은 MapLibre만 소유

## D-007. 중복 좌표 신뢰도 하향

- 상태: 확정
- 계기: 대청도·백령도 필지 검토
- 발견: 서로 다른 상세 주소가 동일 위경도를 공유하는 경우 존재
- 결과: 위치는 유지하되 `상세 주소 좌표`가 아닌 `대표 위치`로 표시하고,
  동일 좌표 공유 주소 수를 설명

## D-008. 지도에서 사이드바 자동 축소

- 상태: 확정
- 이유: 지도는 가로 공간이 핵심이며 다른 메뉴는 전체 메뉴 탐색이 중요함
- 결과: `/map` 진입 시 아이콘형으로 자동 축소, 다른 메뉴는 확장
- 수동 토글 기능은 코드에 보존하되 현재 UI에서는 숨김

## D-009. 장기 엔티티 그래프

- 상태: 후속 버전 목표
- 내용: 인물뿐 아니라 종목·코인·지역·기관·자산 유형마다 고유 상세 페이지를
  제공
- 선행 조건: 안정 ID, 별칭 사전, 관계 신뢰도, 역추적 가능한 lineage
